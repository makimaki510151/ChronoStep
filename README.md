# Chrono Step（クロノ・ステップ）

公開情報型の戦略すごろくです。非公開の乱数に頼らず、場に並んだダイスの選択とパネル設置で生き残りを争います。

## 遊び方

1. **部屋を作る（ホスト）** → 部屋コードを共有
2. 友達は **部屋に入る（ゲスト）** で同じコードを入力
3. ホストが「ゲーム開始」
4. 公開ダイスから1つ選び、出目ぶん進む（1マス＝タイム1）
5. 空きマスならパネルを設置。タイム0で脱落、最後の1人が勝ち

ローカル対戦（同一端末のホットシート / CPU）もできます。

## ルール要約

| 要素 | 内容 |
| --- | --- |
| タイム | 初期100。0以下で脱落 |
| ダイス | 生存人数＋1個を公開。余り1個は破棄 |
| 盤面 | 本線24マス＋分岐ショートカット6×2 |
| パネル | ドレイン / ブースト / リバース / ロック（各2枚） |
| 踏みつけ | 同マス停止で −5 / ＋5 |
| サドンデス | 11ラウンド目以降の終了時、全員 −5 |

## 技術

- 静的フロントエンド（ES Modules）
- 描画: Canvas 2D
- 通信: [PeerJS](https://peerjs.com/)（WebRTC DataChannel、ホスト権威）

MkMk Street と同様に GitHub Pages でそのまま公開できます。
